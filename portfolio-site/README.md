# 🌌 Vaibhav Chhabra — Portfolio (Next.js Application)

This directory contains the Next.js source code for **Vaibhav Chhabra's Developer Portfolio**.

Refer to the main [Root README](../README.md) for full project documentation, tech stack details, and customization guides.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build

# Start production server
npm run start

# Type check & Lint
npm run type-check
npm run lint
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

---

## ⚙️ Content & Configuration

To modify any content on the site, edit the files in [`src/data/`](./src/data/):
- **`site.ts`**: Global settings, social links, resume link, bio, and section visibility.
- **`projects.ts`**: Projects showcase, tech stacks, and links.
- **`skills.ts`**: Technical skill groups and proficiency.
- **`experience.ts`**: Education, internships, and achievements.
- **`competitive.ts`**: LeetCode and CodeChef profiles & statistics.
